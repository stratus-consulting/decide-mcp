# Security

## Reporting a vulnerability

Please don't open a public issue for security problems.

Email [engage@stratusgroups.com](mailto:engage@stratusgroups.com) with:

- what you found and where (endpoint, tool, field)
- steps to reproduce
- the potential impact

We'll acknowledge your report and provide updates as the investigation progresses.

## In scope

- The hosted service at `https://stratus-decide.onrender.com`, including `/mcp` and `/v1/*`
- The code and examples in this repository

## Out of scope

- Denial-of-service or load testing
- Social engineering of Stratus staff
- Findings that rely on a leaked or stolen API key

## Please don't

- Submit real client, customer or personal data while testing
- Try to extract the service's internal rules, prompts or methodology
- Access, modify, or disclose another user's data. If you encounter sensitive information, stop testing and report it privately.
